# forge-form
A mobile fitness planner allowing for exercise logging as well as workout program creation and organization. Initially developed as a final project for Lake Superior College's Mobile App Development course.

***PLATFORM:*** Android  
***DEVELOPMENT FRAMEWORK:*** Apache Cordova  

***CURRENT FEATURES:***  
1.	Signup/login functionality 
2.	Ability to create workout programs and store them in a database
3.	Ability to create exercises for those programs
4.	Ability to view the programs
5.	Ability to edit the programs
